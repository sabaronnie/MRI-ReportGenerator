2. Flag semantics: clinical abnormality vs quality / caution

How I would classify the current flags:
- `tilt_outlier`: quality / caution flag, not a stand-alone clinical abnormality flag. In the plan it is described as "unusual axis orientation; likely segmentation issue."
- `ap_width_outlier`: caution / review flag. It means outside the typical range sanity window used by the geometry pipeline; I would not treat it as a diagnosis by itself.
- `wedge_fracture`: intended pathology-style review flag.
- `biconcave_fracture`: intended pathology-style review flag.
- `spondylolisthesis_present`: intended pathology-style review flag, with an explicit supine-MRI caveat.

Important nuance: the current interpretation scaffold in code auto-recognizes quality flags by names like `low_confidence`, `misaligned`, `approximate`, etc. Because `tilt_outlier` does not contain one of those markers, the scaffold may currently treat it more like a pathology flag than I intend. So on your healthy-set analysis, I would not count `tilt_outlier` the same way you would count `wedge_fracture` or `spondylolisthesis_present`.

3. Is `tilt_deg` measured against image vertical? Is ~28 degrees expected?

`tilt_deg` is measured against the global superior-inferior axis after canonical reorientation, not the raw pixel-grid "screen vertical" from the original file. Concretely, the code computes the angle between the vertebra's local SI axis and the global SI direction in the sagittal PA-SI plane.

Given that definition, the fact that your healthy set is clustering around ~28 degrees is a strong sign that the current `20` degree threshold is too aggressive for cervical anatomy / positioning, or that the local axis being extracted is not behaving as intended on these masks. Either way, I would interpret that result as "threshold / geometry issue to recalibrate," not "83% of healthy vertebrae are clinically abnormal."

4. Anterior vs posterior height expectation

I would not expect a healthy cervical series to have a systematic strong anterior-greater-than-posterior signature that contradicts established lordotic wedging. Mild anterior-less-than-posterior in healthy cervical bodies is plausible and consistent with the literature direction you mention.

So if your independently validated method reads the same healthy necks as posterior > anterior while my current morphometry is producing anterior > posterior, I would treat that as something real to reconcile, not as a harmless convention difference to ignore. The first suspects I would check are:
- corner placement on tilted bodies
- body isolation / posterior-element trimming
- how the local PCA frame is chosen on oblique or irregular slices

5. Healthy slip expectation and the 1 mm / 2 mm cutoffs

The current code constants are:
- `NEUTRAL_THRESHOLD_MM = 1.0`
- `SPONDY_PRESENT_THRESHOLD_MM = 2.0`

So yes: in the current implementation, below 1 mm is effectively neutral, and 2 mm or more is flagged as `spondylolisthesis_present`.

Conceptually, on healthy supine MRI I would expect slip to stay near zero and mostly below the present threshold. I would not expect 50% positives on healthy adjacent pairs. If you are seeing SD about 3.4 mm and range about +/-9.6 mm on healthy data, I would treat that as evidence that the upstream corner stability / body-isolation geometry still needs work before trusting those flags.
