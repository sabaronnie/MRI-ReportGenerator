# MRI-ReportGenerator — paper (LaTeX, Overleaf-ready)

## How to compile (Overleaf)
1. Upload the whole `paper/` folder to a new Overleaf project (or drag-drop the zip).
2. Set **Menu → Compiler → pdfLaTeX**, **Main document → `main.tex`**.
3. Press **Recompile**. (BibTeX runs automatically on Overleaf; if a local build, run
   `pdflatex → bibtex → pdflatex → pdflatex`.)

## Structure
- `main.tex` — document class, packages, title, and `\input` of every section.
- `sections/00_abstract.tex … 18_conclusion.tex` — one file per section.
- `appendix/` — per-case data table, threshold catalog, extra figures (see `\input` block in main.tex).
- `figures/` — matplotlib strip plots from the validation (open-source generated); the pipeline diagram
  is TikZ (in `04_system_architecture.tex`), so it needs no external image.
- `references.bib` — bibliography (identifiers from the project's verified-research notes).

## Notes
- Figures are regenerated by `~/dev/group5-proto/run_validation_master.py` (matplotlib) into `figures/`.
- All clinical numbers carry citations; uncertain identifiers use a conservative `@misc` form rather than
  a fabricated author string.
