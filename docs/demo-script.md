# Demo Script

Suggested live demo flow:

1. Submit a sagittal cervical MRI case to the EEP.
2. Show segmentation outputs from `services/segmentation/`.
3. Show measurement JSON from `services/measurements/`.
4. Show interpreted findings from `services/interpretation/`.
5. Show final structured report output from `services/reporting/`.

Keep one known-good case prepared locally for the rubric demo.
