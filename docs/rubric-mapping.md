# Rubric Mapping

This file maps the repo structure to the project rubric:

- Public endpoint / orchestration: `services/eep/`
- Internal AI service 1: `services/segmentation/`
- Internal AI service 2: `services/measurements/`
- Interpretation layer: `services/interpretation/`
- Report generation: `services/reporting/`
- Validation / experiments: `research/`, `colab/`
- Integration / E2E tests: `tests/integration/`, `tests/e2e/`
- Deployment evidence: `deployment/`
- Architecture and demo docs: `docs/`
