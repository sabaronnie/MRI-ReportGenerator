Phase 4 Threshold / Range Research List
Generated: 2026-06-06

Purpose
- This file is a handoff list for literature-search work.
- Goal: identify every pipeline measurement or derived assessement output that may need:
  - normative ranges
  - abnormal thresholds
  - severity bands / labels
  - population-specific caveats
- This file mixes:
  - implemented outputs already present in code
  - planned core outputs documented in the master plan / phase files
  - experimental outputs that may still need threshold policy if we keep them

General research instructions for the next model
- Prefer healthy / asymptomatic cervical MRI normative studies first.
- If only radiograph or CT literature exists, capture that clearly as a modality caveat.
- Always note whether thresholds are for standing radiographs, supine MRI, CT, or mixed cohorts.
- Capture whether results are per vertebral level, per disc level, or global.
- Capture whether age, sex, and/or height adjustment is recommended.
- Distinguish:
  - raw measurement thresholds
  - derived classification labels
  - quality / caution thresholds that are not true pathology thresholds

Status legend
- Implemented: code exists now
- Planned: described in plan, not fully wired into service yet
- Experimental: low-confidence / stretch feature

1. Vertebral Body Measurements
==================================================

1.1 Vertebral body AP width
- Output key(s): AP_width
- Clinical name: vertebral body anterior-posterior width
- Phase / status: 3A.1 / Implemented
- Scope: per vertebra, currently C3-C7 in canonical producer
- Research needed:
  - normative per-level AP width ranges
  - whether age- and sex-stratified tables exist
  - whether any pathology-oriented thresholds are published or if this should remain mainly a reference/sanity metric
- Existing code hints:
  - current sanity window only: 12-22 mm
  - current flag name: ap_width_outlier
- Caveats:
  - current outlier threshold is engineering sanity logic, not a validated clinical pathology threshold
  - anterior osteophytes may inflate AP width
  - vertebral body extraction is MRI-mask-based adaptation, not direct radiologist caliper measurement

1.2 Vertebral body heights
- Output key(s): H_anterior, H_middle, H_posterior
- Clinical name: anterior, middle, posterior vertebral body SI height
- Phase / status: 3A.2 / Implemented
- Scope: per vertebra
- Research needed:
  - normative per-level height ranges
  - age/sex effects
  - whether height ratios are more clinically meaningful than absolute heights for cervical MRI
- Caveats:
  - based on Genant-style morphometry adapted from radiograph literature
  - TSS endplate under-segmentation may bias heights low
  - absolute norms may be less portable than intra-vertebral ratios

1.3 Wedge fracture / wedge deformity rule
- Derived from: H_anterior versus H_posterior
- Current code / plan logic:
  - wedge when H_anterior < 70% of H_posterior
- Phase / status: 3A.2 / Implemented as flag
- Research needed:
  - confirm whether 70% is appropriate for cervical MRI adaptation
  - find cervical-specific or closest morphometric fracture criteria
  - determine desired labels: normal / mild / moderate / severe wedge? or binary review flag?
- Caveats:
  - literature basis is Genant semiquantitative vertebral fracture assessment, originally not cervical MRI
  - likely should be treated as review flag pending validation

1.4 Biconcave fracture / central height loss rule
- Derived from: H_middle relative to corner heights
- Current code / plan logic:
  - biconcave when H_middle < 70% of max(corner heights)
- Phase / status: 3A.2 / Implemented as flag
- Research needed:
  - same questions as wedge fracture
  - find whether cervical-specific semiquantitative criteria exist
- Caveats:
  - same modality / anatomy adaptation issue as above

1.5 Vertebral tilt
- Output key(s): tilt_deg
- Phase / status: 3A.1 / Implemented
- Research needed:
  - decide whether this should have any published range search at all
  - if yes, search for expected vertebral body local-axis tilt on midsagittal cervical MRI
- Existing code hints:
  - current caution threshold only: 20 degrees
  - current flag name: tilt_outlier
- Caveats:
  - this is best treated as a quality / geometry caution metric, not a clinical abnormality metric
  - user explicitly considers it a caution flag, not pathology

2. Spondylolisthesis / Slip
==================================================

2.1 Slip magnitude
- Output key(s): spondy_slip_mm
- Clinical name: vertebral slippage magnitude in mm
- Phase / status: 3A.3 / Implemented
- Scope: adjacent vertebral pairs
- Research needed:
  - normal / physiologic slip on healthy supine cervical MRI
  - abnormal thresholds in mm
  - whether thresholds differ for anterolisthesis vs retrolisthesis
- Existing code hints:
  - neutral threshold: < 1 mm
  - present threshold: >= 2 mm
- Caveats:
  - supine MRI underestimates functional slip compared with standing/flexion-extension radiographs
  - literature may be mostly radiographic, not MRI-based

2.2 Slip percentage
- Output key(s): spondy_pct_of_lower_AP
- Clinical name: slip percentage relative to lower vertebral AP width
- Phase / status: 3A.3 / Implemented
- Research needed:
  - whether cervical literature reports slip as percent and what normal values are
  - whether percent-based severity is meaningful on cervical MRI
- Caveats:
  - denominator depends on vertebral AP width measurement stability
  - likely mainly a bridge to Meyerding grade

2.3 Meyerding grade
- Derived from: spondy_pct_of_lower_AP
- Current labels:
  - Grade I: 0-25%
  - Grade II: 25-50%
  - Grade III: 50-75%
  - Grade IV: 75-100%
  - Grade V: >100%
- Phase / status: 3A.3 / Implemented
- Research needed:
  - whether Meyerding should be retained as-is for cervical use or only cited as borrowed convention
  - whether cervical-specific grading alternatives exist
- Caveats:
  - Meyerding is historically lumbar-oriented
  - our code already surfaces a mandatory supine caveat

3. Disc Geometry / Disc Degeneration Proxies
==================================================

3.1 Disc SI heights
- Output key(s): disc_H_anterior, disc_H_middle, disc_H_posterior, disc_H_mean, disc_H_center
- Clinical umbrella term: disc SI height
- Phase / status: 3A.4 / Implemented
- Scope: per disc level
- Research needed:
  - which of these disc height variants actually have literature support
  - whether the report should use middle height, mean height, center height, or only a derived index
  - normative ranges by level
- Caveats:
  - plan mainly discusses disc SI height generally, not all five variants separately
  - C2-C3 may behave differently anatomically due to dens / upper cervical geometry

3.2 Disc AP width
- Output key(s): disc_AP_width
- Phase / status: 3A.5 / Implemented
- Research needed:
  - normative disc AP width by level if available
  - whether absolute AP width alone is clinically useful or only relative to adjacent vertebral body width
- Caveats:
  - likely more useful as input to bulge logic than as a standalone thresholded finding

3.3 Disc Height Index
- Output key(s): DHI, DHI_anterior, DHI_posterior
- Phase / status: 3A.6 / Implemented
- Research needed:
  - normative cervical DHI ranges
  - reduced DHI thresholds
  - whether anterior/posterior variants have literature support or should stay internal
- Existing code hints:
  - reduced_dhi currently fires when DHI < 0.30
- Caveats:
  - plan says exact threshold still belongs to Phase 4
  - literature may vary on denominator convention

3.4 Disc bulge / protrusion proxies
- Output key(s): disc_vb_ap_ratio, posterior_bulge_mm
- Related helper key: vb_ap_width_ref
- Phase / status: 3A.5 / Implemented
- Research needed:
  - thresholds for relative disc AP expansion vs adjacent vertebral body width
  - posterior contour excursion thresholds in mm
  - whether these should map to labels like no bulge / bulge / protrusion or remain review-only
- Existing code hints:
  - current flag: disc_bulge_present when posterior_bulge_mm >= 2.0 or ratio >= 1.10
- Caveats:
  - current implementation is an engineering proxy, not a validated radiologist-grade herniation classifier
  - literature may use axial imaging for true protrusion/herniation definitions

3.5 Disc signal class / experimental Pfirrmann-like output
- Output key(s): pfirrmann_grade, nucleus_csf_ratio, nucleus_norm, heterogeneity, na_contrast_norm
- Phase / status: 3C.2 / Experimental, partially implemented under legacy name
- Research needed:
  - whether to keep this feature at all
  - if kept, find cervical disc signal grading literature or justify relative within-subject classifier labels
  - determine final labels if not true Pfirrmann
- Caveats:
  - project plan explicitly says this is not true Pfirrmann grading
  - should be labeled experimental if retained

4. Canal / Cord / Stenosis Measurements
==================================================

4.1 Functional canal / dural sac AP minimum
- Output key(s): dural_sac_AP_min
- Clinical name: functional canal AP or dural sac AP diameter
- Phase / status: 3B/3.1 / Implemented
- Scope: per vertebral level
- Research needed:
  - normative MRI ranges for soft-tissue canal / dural sac AP
  - stenosis thresholds
  - severity bands
- Existing code / plan hints:
  - plan preview uses >13 mm normal, 10-13 mm borderline, <10 mm absolute stenosis
- Caveats:
  - implemented code measures soft-tissue canal space with SCT, not true osseous canal
  - should not be conflated blindly with bony canal thresholds from CT/radiographs
  - current value is a stable minimum across slices, not a single manual caliper point

4.2 Osseous canal AP diameter
- Output key(s): canal_AP
- Phase / status: 3A.7 / Planned in docs, not current default implementation
- Research needed:
  - normative bony canal AP ranges by level
  - same stenosis thresholds and severity bands
- Caveats:
  - this is distinct from dural_sac_AP_min
  - if both stay in scope, literature search must keep them separate

4.3 Cord AP diameter
- Output key(s): cord_AP
- Phase / status: 3B.2 / Implemented
- Research needed:
  - normative cord AP ranges by level
  - age/sex adjustment rules
  - whether external healthy-control normalization is available
- Caveats:
  - current code aligns cord AP to the focal slice chosen by canal narrowing logic
  - slice misalignment and missing-level flags matter
  - plan mentions SCT supports broader morphometrics than current code exposes

4.4 Cord CSA and related SCT morphometrics
- Output key(s): planned, not fully surfaced now
  - area / CSA
  - diameter_RL
  - eccentricity
  - solidity
- Phase / status: 3B.2 / Planned
- Research needed:
  - normative ranges
  - whether any of these belong in v1 report or only in research appendices
- Caveats:
  - not all are currently exposed in service outputs
  - would need clear clinical justification before surfacing

4.5 SAC (Space Available for Cord)
- Output key(s): SAC
- Phase / status: 3B.3 / Implemented
- Research needed:
  - confirm high-risk threshold(s)
  - determine whether severity bands exist or whether binary risk flag is enough
- Existing code / plan hints:
  - current / planned rule: SAC < 3 mm = high compression risk
- Caveats:
  - derived from same-slice subtraction; reliability depends on slice alignment
  - may be stronger as risk flag than as full severity ladder

4.6 Torg-Pavlov ratio
- Output key(s): Torg_Pavlov_ratio or similar future name
- Phase / status: 3A.8 / Planned
- Research needed:
  - MRI-specific ratio thresholds
  - whether C4-C6-only flagging is justified
- Existing plan hint:
  - classic threshold < 0.8 for developmental stenosis
- Caveats:
  - originally radiograph-based
  - MRI may need slightly adjusted thresholds

4.7 Maximum spinal cord compression / maximum canal compromise
- Output key(s): MSCC, MCC or SCT equivalents
- Phase / status: 3B.4 / Planned
- Research needed:
  - formulas, severity cutoffs, and label bands
  - healthy-control normalization assessement
- Caveats:
  - depends on identified compression site
  - fully automated path relies on SCT detection first

4.8 Compression detection / compression ratio rule
- Output key(s): compression detection output from SCT, possibly CR-derived labels
- Phase / status: 3B.5 / Planned
- Research needed:
  - threshold/label logic for automated compression-site detection
  - whether this should be surfaced as a binary tool output or translated into our own report language
- Caveats:
  - Horakova validation applies only to C3-C4 through C6-C7 disc levels

4.9 Most stenotic level
- Output key(s): most_stenotic_level_by_dural_sac and/or lowest_sac_level
- Phase / status: 3A.9 / Partially implemented via group3 summary
- Research needed:
  - no direct normative range needed
  - need policy for how to label/report it using underlying canal/SAC severity
- Caveats:
  - this is a derived summary, not an independently thresholded measurement

5. Global / Segmental Alignment
==================================================

5.1 Global Cobb angle
- Output key(s): Cobb_C3_C7
- Phase / status: 3A.10 / Implemented
- Research needed:
  - asymptomatic cervical alignment ranges
  - classification cutoffs for lordotic / straightened / kyphotic
  - explicit supine MRI adjustment or caveat
- Existing code / plan hints:
  - current classification thresholds use 0 deg and 10 deg
  - plan cites mean ~13.9 +/- 12.3 deg in asymptomatic adults
- Caveats:
  - standing radiograph literature dominates; MRI is supine and under-measures lordosis
  - ensure convention (C3-C7 inferior-inferior here, not always C2-C7 in papers)

5.2 Lordosis classification
- Output key(s): metadata label now, future assessed output
- Current labels in code:
  - kyphotic
  - straightened / low lordosis
  - lordotic
- Phase / status: 4 / Implemented as derived classification
- Research needed:
  - final label set
  - whether thresholds should be MRI-specific
- Caveats:
  - classification is explicitly approximate in current code

5.3 Segmental angles
- Output key(s): segmental_angle
- Phase / status: 3A.11 / Implemented
- Scope: C3-C4 through C6-C7 currently
- Research needed:
  - normal per-level segmental lordosis / kyphosis ranges
  - definition of focal kyphosis thresholds
- Caveats:
  - global alignment may be normal while one segment is not
  - literature conventions may vary by endplates used

5.4 Posterior tangent angle
- Output key(s): posterior_tangent_C3_C7
- Phase / status: Implemented secondary metric
- Research needed:
  - whether we want external normative ranges for this as a reportable metric
  - or whether it remains only a cross-check / secondary descriptor
- Caveats:
  - current code treats this as a secondary / cross-check metric
  - likely lower priority than Cobb

7. Assessement-Level Outputs That Also Need Research / Policy
==================================================

These are not raw measurements, but they still need threshold or label research.

7.1 Myelopathy indicator
- Phase / status: Phase 4 planned
- Inputs:
  - canal narrowing
  - SAC reduction
  - cord signal anomaly and/or cord compression pattern
- Research needed:
  - best combination rule
  - whether literature supports rule-based screening language
- Caveats:
  - must remain advisory, never diagnostic

7.2 Radiculopathy indicator
- Phase / status: Phase 4 planned
- Inputs:
  - reduced DHI
  - disc bulge proxy
- Research needed:
  - whether sagittal-only MRI can support any defensible rule here
  - likely weaker evidence than myelopathy rules
- Caveats:
  - foraminal dimensions are not directly measured

7.3 Severity labels across measurements
- Phase / status: policy work, not fixed yet
- Current project decision:
  - status will be standardized
  - severity labels are not restricted yet because different measurements may need different vocabularies
- Research needed:
  - for each measurement, determine whether severity should be:
    - binary only
    - mild / moderate / severe
    - grade-based (e.g. Meyerding)
    - experimental / review-only

7.4 Demographic percentile comparison
- Phase / status: Phase 4 planned
- Research needed:
  - which measurements should use age/sex normalization from literature
  - which measurements need internal Duke percentile curves instead
- Caveats:
  - Duke is a clinical cohort, not a pure healthy volunteer cohort
  - do not confuse cohort percentile with healthy normative threshold
